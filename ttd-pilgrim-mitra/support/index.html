Support

Most problems are one of two things: the booking page changed shape, or the extension is locked. Both are quick to sort out. If neither is it, send a report and it gets read.

A field did not fill

  1. Look at the boxes on the page. Each box turns green once TTD holds the saved value, and the banner says which box comes next. Only a box that stays without a green check needs your attention.
  2. Press Retry failed. A field that was still loading when the run reached it usually succeeds the second time.
  3. Use Map field on anything still missing. It asks you to point at the box on the page, and it remembers that box for next time. This is the fix when TTD has renamed or moved a field.
  4. Then send a problem report. That tells us the page changed, so the next version recognises the field for everyone without anyone having to map it.

Sending a problem report

Open the extension and press Report a problem. It sits in Settings, in Help, and on the home screen straight after a fill that went wrong.

The report carries the shape of the page and which fields failed: counts, field names, error messages. It leaves out names, ID numbers, phone numbers, email addresses and postal addresses. You are shown the entire report before anything happens, and nothing leaves your computer until you press Copy or Email.

If you type something into the notes box that looks like an ID or a phone number, it warns you rather than sending it quietly.

Writing in directly

twinntricks@gmail.com. Please do not put pilgrim names, ID numbers or phone numbers in the email. Nothing about a problem needs them, and email is not a safe place to keep them.

Questions people ask

I forgot my PIN. Can you reset it?

No one can, including us. The PIN never leaves your computer and is never stored, so there is nothing on our side to reset against. Use the recovery key shown once when you turned the PIN on to set a new one.

Without that key the only way forward is a reset, which erases the saved pilgrims, because the data cannot be read without one of the two. An exported backup has a password of its own, so if you kept one you can reset and import it back. This is the cost of the details being genuinely yours.

Will it book the ticket for me?

No, and it will not try. It helps you enter the pilgrim details and stops. Choosing the date and slot, the OTP, the captcha, pressing Continue and paying are all yours. It does not improve your chances of getting a ticket either. You paste the same details you would have typed, faster and without a mistake.

It says nothing is detected on the page.

It only offers itself on ttdevasthanams.ap.gov.in and tirupatibalaji.ap.gov.in, on the pilgrim details step of a booking. On the login page, the slot picker or the payment page there is nothing for it to fill, which is deliberate.

If you are on the right step and it still sees nothing, reload the page. A tab that was already open when the extension was installed or updated needs one reload before the extension can reach it.

Does it work on my phone?

Not yet. Chrome on Android and iOS does not run extensions at all, so this is a desktop tool. The pilgrim details you save do not sync to a phone either, since they never leave the computer they were saved on.

What happens to my data if I reinstall Chrome?

It goes. The saved pilgrims live in this Chrome profile, so removing the profile, the extension or Chrome itself takes them with it. Nothing is held on a server to restore from.

Settings has an encrypted backup for exactly this. It writes a single .ttdpbackup file, protected by a password you choose for it, that you can keep wherever you keep important files and import later.

Why does it ask to read the TTD site?

Because filling a form means reading it first: finding the name box, the ID box and the row each pilgrim belongs in. That access is limited to the one TTD origin. No other website is requested and no other page is read.

The full reasoning for each of the three permissions is in the privacy policy.

I have twenty relatives to enter. Is there a faster way?

Settings takes a CSV. It writes out a template to start from, and when you bring the filled sheet back it tells you which rows it could not read, by line number, instead of refusing the whole file.

Which photo IDs does it support?

Aadhaar and passport, the two the TTD dropdown accepts, each checked against its own shape so a typo is caught before the form sees it. The page shows which one to pick in the Photo ID Proof dropdown before you paste the number.

How do I get rid of everything?

Settings has Delete all data, which asks you to confirm rather than doing it on a stray click. Removing the extension from Chrome also takes the vault with it. There is no copy anywhere else to chase down.
